# AI/ML Assessment Solutions

This repository contains the executed Kaggle notebooks and concise reports for three end-to-end LLM engineering tasks—covering **fine-tuning (LoRA)**, **retrieval-augmented generation (RAG)**, and **local inference optimisation (Ollama)**—all run on **NVIDIA Tesla T4 GPUs**.
